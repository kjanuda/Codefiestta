# AshenLens

AshenLens is a multimodal intelligent document assistant built for the
SLIIT Codefest 2026 AI Competition.

## Chosen Sub-track

Sub-track 1A — Rich Answers, Not Just Text

## Goal

The system answers questions using the Ashen Era Archive and returns
relevant visual evidence such as images, figure plates, diagrams, and
tables alongside grounded textual answers.
